# Experiment analysis

This offline exercise evaluates one binary primary outcome for two randomized
variants. Its seeded example records are generated locally and are illustrative,
not customer or production data. The analysis reports sample sizes, conversion
rates, absolute and relative lift, a two-sided pooled z-test, and a 95% Wald
interval for the absolute difference.

Run from the repository root:

```bash
python "Exercises/Experiment Analysis/generate_example_data.py" --output "Exercises/Experiment Analysis/examples/experiment.csv"
python "Exercises/Experiment Analysis/experiment_analysis.py" "Exercises/Experiment Analysis/examples/experiment.csv" --output outputs/experiment_analysis.json
```

The generated example uses a fixed seed and can be regenerated byte-for-byte.
Install dependencies with `python -m pip install -r requirements.txt`. Run the
repository checks with `python -m unittest discover -s tests -v`.

The p-value and interval rely on the usual independent-user approximation.
They do not correct for repeated peeking, multiple outcomes, clustering, or
non-random assignment. Real experiments should define the primary metric,
sample-size plan, stopping rule, and guardrails before examining outcomes.
